Datos del negocio

Datos del negocio

Estos datos aparecen impresos en la boleta y se usan como referencia de contacto. Complétalos aquí.

WhatsApp (Evolution API)

Notificaciones automáticas de pedidos por WhatsApp. Completa esto con los datos de tu instancia de Evolution API.
Sugerencia: usa el mismo teléfono del negocio (definido arriba en "Datos del negocio") como número de esta instancia de Evolution API, para mantener consistencia entre WhatsApp y la boleta.

Mercado Pago

Access Token de tu cuenta de Mercado Pago Chile — se usa solo desde esta pestaña admin (con login) para generar links de pago desde Pedidos. Nunca se expone en el catálogo público.

OpenAI (lectura de facturas)

API Key de OpenAI — se usa solo desde esta pestaña admin (con login) para leer fotos de facturas de compra en Proveedores. Nunca se expone en el catálogo público.

Códigos QR (catálogo y reseñas)

Genera un QR para imprimir y pegar en el local. Se arma con un servicio externo gratuito (api.qrserver.com) solo para dibujar la imagen — el link en sí sigue siendo tuyo.

Delivery por distancia

El precio se calcula por la distancia en línea recta desde el local. Más lejos del último tramo, el pedido queda "por coordinar" y el monto lo pones tú en el pedido.
Ver en Google Maps

Stock en la tienda web

Lo pedido y aún no facturado queda apartado. Los productos sin stock salen como "Agotado". Apágalo si tu stock no está al día.

Programa de referidos

Excel

Lee directo el Excel de tu sistema anterior (Código, Producto, P. Costo, P. Venta, P. Mayoreo, Departamento, Existencia, Inv. Mínimo, Tipo de Venta) y también encabezados como Nombre, Precio, Costo, Stock. GRANEL queda "por peso". Si un producto ya existe con el mismo código, se actualiza en vez de duplicarse; su categoría solo cambia si marcas la casilla de arriba.
